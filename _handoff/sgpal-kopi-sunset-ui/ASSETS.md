# Asset provenance and limitations

The four PNGs under `sgpal/web/assets/` were generated for this SG Pal concept using the built-in image-generation tool, with the user's approved Kopi Sunset room/character boards as references. They are original project concept assets, not extracted Habbo, Pokemon or Tamagotchi assets.

- `room.png`: warm isometric Singapore BTO living room, jade sofa, teak console, sunset windows, standing fan, kopi table, empty central terracotta rug; no UI or Pal.
- `merlion.png`: approved cream Merlion with scalloped mane and aqua fish tail, isolated on transparency.
- `otter.png`: approved warm brown otter with cream muzzle and long tail, isolated on transparency.
- `mynah.png`: approved dark rounded mynah with yellow eye patch, beak and feet, isolated on transparency.

The image prompts requested chunky low-resolution shapes, limited palette and native40x40 readability. Image generation did not enforce an exact pixel atlas, so these are displayed as sampled concept art, not claimed as finished production sprites. Canvas UI geometry, bitmap glyphs, item symbols and focus controls are authored in code at integer native coordinates. Captured photographs use ordinary photographic interpolation inside the pixel frame.
